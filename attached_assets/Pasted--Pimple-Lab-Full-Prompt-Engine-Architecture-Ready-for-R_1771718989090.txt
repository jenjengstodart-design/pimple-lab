⚡ PART 0: Token Decision
Use max_new_tokens: 300.

Here's why:


Tokens	Est. Time (L4 GPU)	Room for Output	Risk
200	~25–30s	JSON barely fits, no message field	High truncation
300	~35–45s	JSON + message + hypothesis fits	Low — recommended
400	~55–65s	Lots of room	Borderline UX
500	>70s	Comfortable	Too slow
Loading screen copy: "Running your skin science... usually about 30 seconds 🧪" — sets expectation, feels intentional.

JSON-first strategy: Instruct MedGemma to output { immediately. If truncation hits, you lose the tail of the message field — but the classification fields at the top survive. Parser handles truncated JSON gracefully.

✅ No makeup on the area you want to check

✅ Centre your face / affected area in the frame
✅ Stay still — blurry photos get worse results
✅ Take up to 3 photos and pick the sharpest one

❌ Avoid: flash, dim lighting, dark backgrounds, filters

🤖 PART 3: MedGemma Prompt A — Initial Scan
3a. System Prompt (goes in role: "system")
You are a skin pattern analysis assistant for Pimple Lab, a teen skincare science app.

Your job: analyse the skin photo provided and output a structured hypothesis about what type of skin pattern is visible. You are NOT making a medical diagnosis. You are identifying visible patterns to help a teenager design a skincare experiment.

CRITICAL OUTPUT RULES:
1. Respond with ONLY a valid JSON object. Zero text before or after it.
2. Your very first character must be {
3. Keep the "message" field under 50 words
4. Keep the "hypothesis" field under 20 words
5. If image quality is too poor to assess, still output JSON and set confidence to "low" and include "poor_image_quality" in flags

OUTPUT EXACTLY THIS JSON STRUCTURE (no extra fields):
{
  "skin_tone": "[light or medium or dark — infer from image]",
  "pattern": "[one of: clear, comedonal, papular, pustular, nodular, cystic, mixed]",
  "severity": "[one of: clear, mild, moderate, severe, urgent]",
  "zones": ["[array of: forehead, left_cheek, right_cheek, chin, nose, t_zone, chest, back]"],
  "confidence": "[low or medium or high]",
  "flags": ["[array — include any that apply: possible_fungal, hormonal_pattern, scarring_risk, pih_present, poor_image_quality]"],
  "message": "[2-3 sentences, teen-friendly, hypothesis framing — 'Here's what we think we're seeing…']",
  "hypothesis": "[one sentence: If this is X, then Y should improve in Z timeframe]",
  "see_doctor": [true or false]
}

PATTERN DEFINITIONS (use these exactly):
- clear: no visible active lesions
- comedonal: primarily blackheads or closed bumps under skin, no redness
- papular: small red raised bumps, no pus visible
- pustular: red spots with visible white or yellow pus centres
- nodular: large deep firm painful-looking bumps, no pus
- cystic: large fluid-filled deep sacs, very inflamed
- mixed: combination of two or more types above

SEVERITY RULES:
- clear: no lesions
- mild: few scattered lesions, low inflammation
- moderate: multiple lesions across one or more zones, visible redness
- severe: many lesions, significant inflammation, possible early scarring
- urgent: nodular or cystic pattern, risk of permanent scarring

CONFIDENCE RULES:
- high: image clear, multiple lesions visible and classifiable
- medium: image acceptable but some ambiguity in lesion type
- low: image too dark, blurry, zoomed too close/far, or only 1-2 ambiguous spots

FUNGAL FLAG: Add "possible_fungal" to flags if the user context mentions any of:
itchy spots, no improvement with antibiotic cream, uniform-sized bumps, sweaty sports + oily hair products

URGENCY FLAG: Set see_doctor true AND severity urgent if nodular or cystic pattern visible, or more than 5 large deep lesions

EXAMPLE OUTPUT (follow this format exactly, do not copy the values):
{
  "skin_tone": "medium",
  "pattern": "pustular",

async function callMedGemmaInitial(base64Image, intake, systemPrompt) {
  const userMessage = buildInitialUserMessage(intake);
  
  const response = await fetch(process.env.HF_ENDPOINT_URL, {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.HF_API_TOKEN}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      inputs: {
        messages: [
          {
            role: "system",
            content: systemPrompt   // SYSTEM_PROMPT_A from 3a above
          },
          {
            role: "user",
            content: [
              {
                type: "image_url",
                image_url: { url: `data:image/jpeg;base64,${base64Image}` }
              },
              {
                type: "text",
                text: userMessage
              }
            ]
          }
        ]
      },
      parameters: {
        max_new_tokens: 300,
        return_full_text: false,
        temperature: 0.1,       // Low temp = more consistent JSON output
        do_sample: false        // Greedy decode = more deterministic
      }
    })
  });

  const result = await response.json();
  const rawText = result[0]?.generated_text || result?.generated_text || "";
  return parseMedGemmaResponse(rawText);
}

/**
 * parseMedGemmaResponse
 * Tries 4 strategies in order. Always returns a usable object.
 */
function parseMedGemmaResponse(rawText) {
  if (!rawText || rawText.trim() === "") {
    return { success: false, data: getFallbackObject("empty_response"), method: "empty" };
  }

  const cleaned = rawText.trim();

  // Strategy 1: Direct JSON parse
  try {
    const data = JSON.parse(cleaned);
    if (isValidMedGemmaJSON(data)) {
      return { success: true, data, method: "direct" };
    }
  } catch (e) {}

  // Strategy 2: Extract first complete {...} block
  const jsonBlockMatch = cleaned.match(/\{[\s\S]*?\}(?=\s*$|\s*\n)/);
  if (!jsonBlockMatch) {
    // Try greedy match for nested structures
    const greedyMatch = cleaned.match(/\{[\s\S]*\}/);
    if (greedyMatch) {
      try {
        const data = JSON.parse(greedyMatch[0]);
        if (isValidMedGemmaJSON(data)) {
          return { success: true, data, method: "extracted_greedy" };
        }
      } catch (e) {}
    }
  } else {
    try {
      const data = JSON.parse(jsonBlockMatch[0]);
      if (isValidMedGemmaJSON(data)) {
        return { success: true, data, method: "extracted" };
      }
    } catch (e) {}
  }

  // Strategy 3: Strip markdown code fences
  const codeBlockMatch = cleaned.match(/```(?:json)?\s*([\s\S]*?)```/);
  if (codeBlockMatch) {
    try {
      const data = JSON.parse(codeBlockMatch[1].trim());
      if (isValidMedGemmaJSON(data)) {
        return { success: true, data, method: "markdown" };
      }
    } catch (e) {}
  }

  // Strategy 4: Truncated JSON repair (MedGemma hit token limit mid-JSON)
  const truncatedRepair = repairTruncatedJSON(cleaned);
  if (truncatedRepair) {
    return { success: true, data: truncatedRepair, method: "repaired", warning: "truncated" };
  }

  // Strategy 5: Full prose keyword extraction
  return { success: true, data: extractFromProse(cleaned), method: "prose_fallback" };
}

/**
 * Validate minimum required fields exist
 */
function isValidMedGemmaJSON(data) {
  return data && 
    typeof data === "object" && 
    data.pattern && 
    data.severity && 
    data.confidence;
}

/**
 * Attempt to repair JSON truncated by token limit
 * Adds missing closing brackets and sanitises incomplete string values
 */
function repairTruncatedJSON(text) {
  try {
    // Find the last complete field before truncation
    let json = text;
    
    // Strip anything after the last complete value (comma or closing bracket)
    json = json.replace(/,\s*"[^"]*"\s*:\s*[^,}\]]*$/, ""); // Remove incomplete last field
    json = json.replace(/,\s*"[^"]*"\s*$/, "");               // Remove dangling key
    json = json.replace(/"[^"]*$/, '"[truncated]"');           // Close open string
    
    // Count brackets and close them
    const openBraces = (json.match(/\{/g) || []).length;
    const closeBraces = (json.match(/\}/g) || []).length;
    const openBrackets = (json.match(/\[/g) || []).length;
    const closeBrackets = (json.match(/\]/g) || []).length;
    
    json += "]".repeat(Math.max(0, openBrackets - closeBrackets));
    json += "}".repeat(Math.max(0, openBraces - closeBraces));
    
    const data = JSON.parse(json);
    if (isValidMedGemmaJSON(data)) return data;
  } catch (e) {}
  return null;
}

/**
 * Pure prose fallback — keyword extraction
 * Returns a minimal, honest object when all JSON strategies fail
 */
function extractFromProse(text) {
  const lower = text.toLowerCase();

  // Pattern detection (order matters — most severe first)
  let pattern = "mixed";
  if (lower.match(/cyst/)) pattern = "cystic";
  else if (lower.match(/nodule|nodular/)) pattern = "nodular";
  else if (lower.match(/pustule|pustular|pus-filled|whitehead.*inflam|pus/)) pattern = "pustular";
  else if (lower.match(/papule|papular|red bump/)) pattern = "papular";
  else if (lower.match(/comedone|blackhead|whitehead|blocked pore|clogged/)) pattern = "comedonal";
  else if (lower.match(/clear|no (active|visible) lesion|no acne|healthy/)) pattern = "clear";

  // Severity detection
  let severity = "moderate";
  if (pattern === "cystic" || pattern === "nodular") severity = "urgent";
  else if (lower.match(/\burgent\b|\bsevere\b|\bsignificant\b|\bextensive\b|\bwidespread\b/)) severity = "severe";
  else if (lower.match(/\bmild\b|\bminimal\b|\bfew\b|\bscattered\b|\boccasional\b/)) severity = "mild";
  else if (lower.match(/\bclear\b|no lesion|no acne/)) severity = "clear";

  // Zone detection
  const zones = [];
  if (lower.includes("forehead")) zones.push("forehead");
  if (lower.includes("left cheek")) zones.push("left_cheek");
  if (lower.includes("right cheek")) zones.push("right_cheek");
  if (lower.includes("cheek") && !lower.includes("left cheek") && !lower.includes("right cheek")) {
    zones.push("left_cheek", "right_cheek");
  }
  if (lower.match(/\bchin\b|\bjaw/)) zones.push("chin");
  if (lower.match(/\bnose\b|t-zone|t zone/)) zones.push("nose");
  if (lower.includes("chest")) zones.push("chest");
  if (lower.includes("back")) zones.push("back");
  if (zones.length === 0) zones.push("face"); // fallback

  // Confidence — prose fallback is always lower
  let confidence = "low";
  if (lower.match(/\bclearly\b|\bdefinitely\b|\bconfident\b/)) confidence = "medium";

  // Flags
  const flags = ["poor_image_quality"]; // Always flag prose fallback
  if (lower.match(/\bfungal\b|\bmalassezia\b|\bfolliculitis\b/)) flags.push("possible_fungal");
  if (lower.match(/\bhormonal\b/)) flags.push("hormonal_pattern");
  if (lower.match(/\bscar/)) flags.push("scarring_risk");
  if (lower.match(/hyperpigment|dark spot|pih|post-inflammatory/)) flags.push("pih_present");

  // Skin tone
  let skin_tone = "medium";
  if (lower.match(/\bfair\b|\blight skin\b|\bpale\b/)) skin_tone = "light";
  if (lower.match(/\bdark skin\b|\bdeep(er)? skin\b|\bmelanin-rich\b/)) skin_tone = "dark";

  const see_doctor = ["urgent", "severe"].includes(severity) || 
                     ["cystic", "nodular"].includes(pattern);

  return {
    skin_tone,
    pattern,
    severity,
    zones,
    confidence,
    flags,
    message: "We had a bit of trouble reading the photo clearly — try retaking it in better lighting for a sharper result. Here's our best guess based on what we could see.",
    hypothesis: "Results are uncertain — see suggestions below",
    see_doctor,
    _method: "prose_fallback"
  };
}

/**

function generateExperiment(medgemma, intake) {

    biological_sex, is_itchy, antibiotic_cream_no_improvement,
    plays_sport_sweats, uses_oily_hair_products, is_uniform_size,
    cycle_stage, acne_worsens_before_period, tried_before
  } = intake;

  // ── URGENT: Refer to doctor immediately ──────────────────────────────
  if (severity === "urgent" || ["cystic", "nodular"].includes(pattern)) {
    return {
      type: "urgent",
      title: "🚨 This needs a doctor, not an experiment",
      hypothesis: "Over-the-counter products won't be enough for this level of acne",

/**
 * Calculates an overall confidence % for display to the user
 * Capped at 90% — this is never a medical diagnosis
 */
function calculateConfidenceScore(medgemma, intake, parseMethod) {
  let score = 0;

  // MedGemma self-reported confidence
  const confMap = { high: 35, medium: 22, low: 8 };
  score += confMap[medgemma.confidence] || 10;

  // Image quality
  if (!medgemma.flags.includes("poor_image_quality")) score += 20;
  else score -= 5;

  // Parse method quality
  const parseMap = {
    direct: 20,
    extracted: 18,
    extracted_greedy: 15,
    markdown: 15,
    repaired: 8,
    prose_fallback: 0
  };
  score += parseMap[parseMethod] || 0;

  // Intake data completeness (each field worth ~1.5 pts, max 15)
  const keyFields = ["age","biological_sex","concern_zones","is_itchy","is_painful",
                     "is_uniform_size","duration_weeks","tried_before","family_acne_history"];
  const filled = keyFields.filter(f => 
    intake[f] !== null && intake[f] !== undefined && intake[f] !== ""
  ).length;
  score += Math.round((filled / keyFields.length) * 15);

  // Pattern specificity (mixed = less certain)
  if (medgemma.pattern !== "mixed" && medgemma.pattern !== "unclear") score += 8;

  // Truncation/fallback penalty
  if (medgemma._method === "prose_fallback") score -= 15;

  // Hard cap: never claim 100%
  return Math.min(Math.max(Math.round(score), 12), 90);
}

/**
 * Assembles the final card shown to the teen
 * Pulls from MedGemma output + experiment engine
 */
function formatResultCard(medgemma, experiment, confidenceScore, parseMethod) {
  const isUncertain = confidenceScore < 40 || medgemma.flags.includes("poor_image_quality");
  const isFallback = parseMethod === "prose_fallback";

  const card = {
    // Header
    title: experiment.title,
    confidence_percent: confidenceScore,
    confidence_label: confidenceScore >= 70 ? "Good signal" 
                    : confidenceScore >= 45 ? "Uncertain — use as a starting point" 
                    : "Low confidence — try a clearer photo",

    // What we see
    what_we_see: medgemma.message,

    // Legal/ethical disclaimer (always shown)
    disclaimer: "This is our best hypothesis — not a medical diagnosis. Use it as a starting point for your experiment, not as medical advice.",

    // Poor image warning
    ...(isUncertain ? {
      image_warning: "📷 The photo quality made this harder to assess. Try retaking in brighter lighting for a sharper result next time."
    } : {}),

    // The experiment
    hypothesis: experiment.hypothesis,
    experiment_question: experiment.experiment_question,
    duration_days: experiment.duration_days,
    check_in_date: experiment.duration_days 
      ? new Date(Date.now() + experiment.duration_days * 86400000).toLocaleDateString("en-GB") 
      : null,

    // Purge warning (if retinoid)
    ...(experiment.purge_warning ? {
      purge_warning: experiment.purge_message
    } : {}),

    // Products
    products: experiment.products,
    avoid: experiment.avoid,
    tips: experiment.routine_tips || [],

    // Skin tone specific note
    ...(medgemma.skin_tone === "dark" && experiment.skin_tone_note ? {
      skin_tone_note: experiment.skin_tone_note
    } : {}),

    // Check-in prompt
    check_in_prompt: experiment.check_in_prompt,

    // Urgent escalation
    see_doctor: medgemma.see_doctor || experiment.see_doctor,
    ...(medgemma.see_doctor || experiment.see_doctor ? {
      doctor_message: "🚨 Based on what we can see, please see a GP or dermatologist soon. This level of acne can cause permanent scarring — get professional help before trying to treat it yourself."
    } : {})
  };

  return card;
}
